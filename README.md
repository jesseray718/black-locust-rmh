# black-locust-rmh

**Carbon-negative thermal cascade and permaculture-oriented heat system within the OpenRoot lattice.**

## What this is

This repository holds designs, notes, and integration points for a rocket-mass-heater-style / thermal-cascade system using black locust and related permaculture principles. It is intended as a practical, low-power, high-usefulness thermal spoke of the larger OpenRoot system.

## Role in the Lattice

This is a physical thermal spoke.  
It supplies real heat and thermal mass behavior that can be measured and accounted for in the thermodynamic ledgers maintained by UNE and OpenRoot.

## Bigger Picture

OpenRoot treats energy, materials, and coordination as a single problem. A working, measurable, carbon-negative or carbon-light thermal system is one of the concrete ways the lattice produces real useful work for the lowest-capability node instead of remaining theoretical.

## Current Status

Active spoke. Designs and integration points are present; physical iteration continues.
